# Visão Geral dos Agentes de IA para o Projeto Vim Config

Este diretório contém definições em **Markdown** para diferentes agentes que auxiliam no desenvolvimento da configuração do Vim. Cada arquivo descreve o objetivo, fluxo de trabalho e instruções específicas que devem ser seguidas pelo agente.

- `overview.md` – Visão geral do propósito dos agentes.
- `plugin_addition.md` – Como adicionar novos plugins ao `vimrc`.
- `documentation_workflow.md` – Atualização da documentação (`README.md`).
- `testing_workflow.md` – Passos para validar a sintaxe e funcionalidade.

Esses arquivos são ignorados pelo Git (via `.gitignore`) para permitir personalização local sem impactar o repositório.
